# Riverlane

> Riverlane is a Cambridge (UK) quantum computing company building the quantum error correction
> (QEC) stack: Deltaflow, a real-time QEC system for qubit readout, decoding, logical operations
> and orchestration; and Deltakit, an Apache-2.0 open-source Python SDK for designing, simulating,
> decoding and analysing QEC experiments. The public developer surface is the Deltakit Cloud API at
> https://deltakit.riverlane.com/proxy — a bearer-token service with two coexisting versions
> (GraphQL v1, asynchronous REST task API v2) that fronts Riverlane's proprietary decoders.

Generated by API Evangelist on 2026-08-05. Riverlane publishes no /llms.txt of its own
(https://www.riverlane.com/llms.txt, https://deltakit.riverlane.com/llms.txt and
https://deltakit-docs.riverlane.com/llms.txt all return 404), so this file is generated from the
API Evangelist profile and the provider's own public artifacts.

## APIs

- [Deltakit Cloud API](https://deltakit.riverlane.com/proxy): Bearer-token cloud service backing the
  Deltakit SDK. Hosts what does not run locally: leakage noise generation and simulation, decoding
  with the proprietary Ambiguity Clustering (AC), Local Clustering (LCD) and Collision Clustering
  (CC) decoders, leakage-aware decoding, iSWAP native-gate circuit generation, quantum stability
  experiment generation, defect rates, correlation matrices, and circuit/detector trimming.
- [GraphQL endpoint (API v1)](https://deltakit.riverlane.com/proxy/api/graphql): POST GraphQL
  documents. Introspection is auth-gated (401).
- REST task API (API v2): `POST /api/v2/tasks/add/{task}`, `GET /api/v2/tasks/get/?request_id=`,
  `DELETE /api/v2/tasks/kill/`. Nine task types: generate_circuit, generate_noisy_stim_circuit,
  generate_si1000_noisy_stim_circuit, decode, decode_leakage, defect_rates, correlation_matrix,
  trim_circuit_and_detectors, simulation.

## Authentication

- One opaque bearer token, sent as `Authorization: Bearer <token>`; 32 characters.
- Free self-serve token at https://deltakit.riverlane.com/dashboard/token (account login required).
- SDK reads `DELTAKIT_TOKEN` from the environment or a persisted config file.
- No OAuth 2.0, no OIDC, no scopes — the discovery documents for all three return 404.

## Known absences (probed, not assumed)

- No `/llms.txt`, no `/.well-known/*` document, no `security.txt` on any Riverlane host.
- No A2A agent card at `/.well-known/agent-card.json` or `/.well-known/agent.json`.
- No MCP server.
- No status page, no SLA, no deprecation policy, no published rate limits, no idempotency contract.
- No webhook, event or streaming surface — job completion is discovered by polling.
- www.riverlane.com and deltakit-docs.riverlane.com return HTTP 403 to non-browser clients
  (Cloudflare bot challenge), so those pages are not machine-readable.
